# Philex Munene Muriithi — Aviation Portfolio

A responsive, single-page personal portfolio for an Aircraft Maintenance Engineering student.

## Included
- Responsive mobile/tablet/desktop layout
- Sticky navigation
- Animated scroll reveal
- Reading progress bar
- Aviation-themed hero section
- About, skills, experience, projects and education sections
- Email and WhatsApp contact buttons
- LinkedIn button
- GitHub Pages-ready static files

## Before publishing
Open `index.html` and replace:
- `YOUR_EMAIL@example.com` with your actual email
- `YOUR_PHONE_NUMBER` with your WhatsApp number in international format, without `+` or spaces
- `https://www.linkedin.com/` with your actual LinkedIn profile

You can also add your CV, certificates and project photographs later.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch.
5. Choose `main` and `/ (root)`.
6. Save.
